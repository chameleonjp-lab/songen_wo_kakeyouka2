# 固定 SNS 紹介画像と X 共有

## 変更と保持範囲

- `assets/social-card.png`: 1200×630 の固定紹介画像。実際のゲーム画面を等比で切り出し、ゲーム名と「壊れた体を引き継ぐ、5連戦。」を組み合わせています。架空のキャラクター・戦闘・スコアを追加していません。
- OG / Twitter large-image 設定と公開ファイル一覧へ同じ画像を登録します。
- 全 15 言語でホームと結果の共有文末尾は `#尊厳を賭けようか2 #ゲーム制作`。
- 部位状態の詳細が長い言語では 280 weighted characters を超える結果があるため、その場合だけ既存翻訳のゲーム名・結果・総合点・勝数・URL・正式 2 タグで短く組み立てます。通常の共有文、結果表示、詳細レポートは省略しません。点数や勝数を丸めません。
- `copyDetailBtn` は詳細レポート専用で、共有文のコピーとは異なるため維持します。通常の共有コピー専用ボタンは追加せず、X の popup が開けない場合の手動コピーも維持します。
- ゲーム規則、時間、難易度、スコア保存、ゲーム識別値、音設定、言語保存は変更しません。

## 検証手順

1. `npm test`: 全 15 言語、部位の正常・負傷・欠損の 243 組、4 結果、符号付き点数で実共有関数の全文・短縮条件・280 weight・元結果不変を検査します。幾何検査には画面外、部分 clipping、祖先の非表示・透明も含みます。
2. `python scripts/test-pages.py` と `python scripts/prepare-pages.py`: 公開物の許可リストを確認します。
3. `npm run test:browser`: 既存の名前・ランキング・ACK・翻訳回帰を維持します。
4. `node scripts/share-visual.mjs` と `BROWSER_ENGINE=webkit node scripts/share-visual.mjs`: 各 engine で全 15 言語の縦画面＋日英独の横画面。通常の匿名開始・リタイア・結果遷移を使い、ホーム／結果の X の黒白表示、44px 操作面、全文字、画面内・祖先 clip・中心 hit、実 intent の正確な本文と呼出し 1 回、結果不変を確認します。
5. 日英独の代表 PNG を実見します。共有ボタンまでスクロールして操作できることの検証であり、結果画面全体が一画面に収まるという意味ではありません。

テストは固定ローカルファイル／ランキング空応答だけを返し、未許可 HTTP・WebSocket・Service Worker を遮断します。リダイレクトを追う upstream fetch は行いません。本番ランキングへの試験スコア送信はしません。
